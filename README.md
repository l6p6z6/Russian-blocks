# 方块竞技场 · Tetris Arena

一个纯前端的俄罗斯方块竞技项目，包含本地账号系统、单人天梯和同机双人分屏对战。

## 功能

### 账号系统
- 本地注册、登录、退出与会话保持
- 用户名 1–16 个字符、密码 1–64 个字符，注册无需二次确认密码
- 支持在同一浏览器中创建多个账号
- 密码使用 PBKDF2-SHA-256 + 随机盐哈希后保存
- 本地保存天梯分、最高分、总消行、对战战绩

### 单人天梯
- 标准 10 × 20 棋盘
- 7-Bag 随机算法、暂存方块、下一块预览、幽灵方块
- 消行计分、等级提升与下落速度加快
- 单行、双行、三行和四行消行使用不同的合成音效
- 提供可持久化的音效开关
- 结束后根据得分、消行和等级调整天梯分
- 当前浏览器内的天梯排行榜与段位显示

### 同机分屏对战
- 玩家一使用当前登录账号
- 玩家二选择另一个本地账号并输入密码验证
- 两块棋盘同屏独立运行
- 双方可同时操作
- 消行向对手发送待处理垃圾行
- 垃圾行会优先被自己的攻击抵消
- 先触顶者落败；双方同帧触顶则判定平局
- 使用独立对战 Elo 分计算胜负变化

## 启动方式

项目不使用构建工具或第三方运行时库。推荐通过本地 HTTP 服务访问，以确保 Web Crypto 可用。

在项目目录执行：

```powershell
python -m http.server 4173
```

然后打开：

```text
http://localhost:4173
```

也可以使用 VS Code 的 Live Server 等静态服务器。

> 不建议直接双击 `index.html` 以 `file://` 协议运行。不同浏览器对本地文件的 Web Crypto 和存储限制不同，需验证。

## 对战规则

1. 单行、双行、三行、四行消除的基础攻击分别为 0、1、2、4 行。
2. 连续消行会产生额外攻击加成。
3. 收到的垃圾行先进入待处理队列，在下一次落块时应用。
4. 下一次消行产生的攻击会优先抵消待处理垃圾行，剩余攻击发送给对手。
5. 天梯分与对战分独立计算。

## 关键设计取舍

### 游戏引擎与界面分离
`js/tetris.js` 不依赖 DOM，负责棋盘、碰撞、旋转、消行、计分和垃圾行。`js/app.js` 只负责输入、渲染和流程协调，因此规则可以独立测试。

### Canvas + DOM 混合渲染
棋盘与方块预览使用 Canvas，账号、排行榜、HUD 和弹窗使用 DOM。这样既保证游戏绘制性能，也便于维护界面和可访问文本。

### 双游戏实例驱动对局
分屏双方各自拥有独立 `TetrisGame` 实例，共享同一个 `requestAnimationFrame` 时钟。对战层只负责攻击转发、暂停和胜负结算。

### 本地账号而非后端账号
账号数据保存在 `localStorage`，当前会话保存在 `sessionStorage`。这样无需服务器即可运行，但数据不能跨设备同步。

## 已知限制与需验证项

- **账号安全限制**：前端账号无法提供服务器级身份认证、权限控制、防篡改、找回密码和防暴力破解能力。虽密码已加盐哈希，但 `localStorage` 中的数据可被本机用户修改。生产环境必须迁移到后端认证。
- **排行榜限制**：天梯榜只统计当前浏览器中的账号，不是全服排行榜。
- **浏览器兼容性**：已使用 Chrome 进行自动化验证；Firefox、Safari 及不同版本移动浏览器需验证，Safari 的 Web Audio 解锁行为也需验证。
- **移动端操作**：当前为键盘操作，移动设备需要另行增加触控按钮。需验证实际触控布局。
- **数据清理**：清除浏览器站点数据会删除全部账号、评分和排行榜。
- **多标签页竞争**：多个标签页同时修改本地账号数据时没有跨标签页同步或冲突合并。
